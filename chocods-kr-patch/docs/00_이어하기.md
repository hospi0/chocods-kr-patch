## 2. 클라우드에서 못 하는 것
- 원본 ROM·빌드 결과물·추출 그림은 저장소에 없다(저작권 + 용량). → **빌드·실기·그림 미리보기(ROM 을 읽는 모든 스크립트)는 로컬에서만.**
- 클라우드에서 할 수 있는 것: 번역문 작성(TSV), 도구 코드 수정, 문서.
- 로컬 경로(바뀌지 않음): ROM `C:\claude\roms\nds\…(Japan).nds`, 설치 `F:\hospi\roms\nds roms\`, melonDS `D:\hospi\melonDS\`.

## 3. 반드시 지킬 규칙(메모리에서 옮김)
- **빌드·디스크 쓰기는 매번 허락받고**(앞 턴 허락은 연장 안 됨). 단계마다 빌드하지 말고 마지막에 한 번.
- **에뮬레이터는 내가 켜지 않는다** — 설치하고 「이 화면 봐 주세요」.
- 사용자에게 보이는 글은 한국어. 질문에는 답만. 안 한 일을 했다고 보고하지 말 것. 근거 숫자는 검증 후.
- 폴더 통째로 지우지 말 것. `my files/` 는 사용자 폴더(예외: 그림 비교는 `my files/그래픽`).
- **그림 수정은 «완성» 선언 말고 사용자 판정에.** 비교 그림은 원본과 나란히 `my files/그래픽` 에.
- 그림 글자 기본: **채움 한 색**(원본에 뚜렷한 그라데이션이 있고 사용자가 원할 때만), **테두리는 새 글자 둘레 1 px**. 사용자가 구체적으로 말하면 원본 따지지 말고 문자 그대로.
- 일본어 고유명사는 거센소리(か행 ㅋ·た행 ㅌ·つ 츠).
- **문장부호 뒤 공백은 빌더에서 지운다**(`, ` → `,`). 길이가 모자라면 ①부호 뒤 공백 ②줄 끝 마침표 ③그다음에야 축약. «안 들어가면 글자 단위로 자르는» 폴백 금지.
- **규칙은 번역을 쓰는 순간 강제**(되채움기에 검사), 빌드 전 전수 검사. 줄 예산은 원문 줄 길이가 아니라 «상자 폭».
- 번역 줄은 셸 이스케이프 말고 파일로 직접 쓴다(음절이 조용히 깨짐).
- 전프로젝트: 일본어 한글화는 가나·한자 슬롯 전부 덮어쓴다.
- 배포 버전은 «v0.9» 꼴, 해시는 MD5, 빌드 후 배포 패치까지 갱신.

## 4. 이 게임 전용 사실
- 글꼴 `romdata/FONT/dsr_fnt.NFTR` 는 SYS 힙(빈 곳 4,416 B)에 올라가서 **크기를 늘리면 부팅 불가** → 한자 칸을 한글로 갈아 끼운다(`nftr.replace_kanji`). 한도 ≈ 880 음절.
- 카드 게임 글꼴 `PUD/font/font.nftr` 도 한자 칸 교체(크기 불변), 번역 전 글이 쓰는 한자는 `work/pud_keep_kanji.txt` 로 남긴다.
- 조사: 번역문에 `{을}{이}{은}{과}{으}{아}{이다}` 로 쓰면 ARM9 훅이 받침 따라 고른다(본편만, 카드 게임 글은 조사를 직접 씀).
- 빌드 명령(로컬): `python tools/build.py <번역 tsv> <out.nds | --dry>` — 본편 텍스트·그림·카드 게임(`tools/pudbuild.py`)·장 제목(`tools/chaptitle.py`)을 한 번에. 끝나면 128 MB 로 0xFF 채움.
- 카드 게임 그림 설정: `work/pud_specs.json`(셀별), 미리보기 `work/pud_run.py`(ROM 필요). 번역: `work/card_ko.tsv`(← `work/card_translate.py`, 문형 `card_lines_ko.py`, 이름 `card_words_ko.py`).
