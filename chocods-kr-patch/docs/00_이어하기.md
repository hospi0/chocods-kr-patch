## 3. 반드시 지킬 규칙(메모리에서 옮김)
- **빌드·디스크 쓰기는 매번 허락받고**(앞 턴 허락은 연장 안 됨). 단계마다 빌드하지 말고 마지막에 한 번.
- **에뮬레이터는 내가 켜지 않는다** — 설치하고 「이 화면 봐 주세요」.
- 사용자에게 보이는 글은 한국어. 질문에는 답만. 안 한 일을 했다고 보고하지 말 것. 근거 숫자는 검증 후.
- 폴더 통째로 지우지 말 것. `my files/` 는 사용자 폴더(예외: 그림 비교는 `my files/그래픽`).
- **그림 수정은 «완성» 선언 말고 사용자 판정에.** 비교 그림은 원본과 나란히 `my files/그래픽` 에.
- 그림 글자 기본: **채움 한 색**(원본에 뚜렷한 그라데이션이 있고 사용자가 원할 때만), **테두리는 새 글자 둘레 1 px**. 사용자가 구체적으로 말하면 원본 따지지 말고 문자 그대로.
- 일본어 고유명사는 거센소리(か행 ㅋ·た행 ㅌ·つ 츠).
- **문장부호 뒤 공백은 빌더에서 지운다**(`, ` → `,`). 길이가 모자라면 ①부호 뒤 공백 ②줄 끝 마침표 ③그다음에야 축약. «안 들어가면 글자 단위로 자르는» 폴백 금지. 번역 파일에도 부호 뒤 공백을 쓰지 않는다(`kocheck.py` 가 오류로 잡음).
- **규칙은 번역을 쓰는 순간 강제**(되채움기에 검사), 빌드 전 전수 검사. 줄 예산은 원문 줄 길이가 아니라 «상자 폭».
- 번역 줄은 셸 이스케이프 말고 파일로 직접 쓴다(음절이 조용히 깨짐).
- 전프로젝트: 일본어 한글화는 가나·한자 슬롯 전부 덮어쓴다.
- 배포 버전은 «v0.9» 꼴, 해시는 MD5, 빌드 후 배포 패치까지 갱신.

## 4. 이 게임 전용 사실
- 글꼴 `romdata/FONT/dsr_fnt.NFTR` 는 SYS 힙(빈 곳 4,416 B)에 올라가서 **크기를 늘리면 부팅 불가**(+2,000 B 까지) → 한자(·가나) 글리프를 빼고 그 자리에 한글(§6).
- 카드 게임 글꼴 `PUD/font/font.nftr` 도 한자 칸 교체(크기 불변), 번역 전 글이 쓰는 한자는 `work/pud_keep_kanji.txt` 로 남긴다.
- 조사: 번역문에 `{을}{이}{은}{과}{으}{아}{이다}` 로 쓰면 ARM9 훅이 받침 따라 고른다(본편만, 카드 게임 글은 조사를 직접 씀).
- 빌드 명령(로컬): `python tools/build.py <번역 tsv> <out.nds | --dry>` — 본편 텍스트·그림·카드 게임(`tools/pudbuild.py`)·장 제목(`tools/chaptitle.py`)을 한 번에. 끝나면 128 MB 로 0xFF 채움.
- 카드 게임 그림 설정: `work/pud_specs.json`(셀별), 미리보기 `work/pud_run.py`(ROM 필요). 번역: `work/card_ko.tsv`(← `work/card_translate.py`, 문형 `card_lines_ko.py`, 이름 `card_words_ko.py`).

## 5. 번역 파일·검사 도구(2026-09-25 추가)
- 번역은 `work/ko/` 폴더에 표별 TSV(`@<TAB>fbc<TAB>안쪽 파일` 머리줄 + `번호<TAB>번역`). 빌드는 폴더째: `python tools/build.py work/ko <out.nds | --dry>`.
  - 00 SYSMSG · 01 UI · 02 DT_ALL 작은 표 · 03‥09 아이템(SJIS) · 10 적 · 11 능력 · 20‥29b 이벤트 EVTMSG0‥10 · 29_cries(자동 생성).
- `tools/kocheck.py [--todo] [--rare N]`: 태그·아이콘·쪽 수·색 짝·줄 폭(상자 폭 예산)·남은 가나·KS X 1001·조사 표지·SJIS 인코딩·편지 합언어·중복 키 검사 + 음절 수. **빌드 전 반드시 오류 0.**
- `tools/kofill.py <tsv>`: 같은 표 안에서 원문이 똑같은 줄에 번역 복사(`# kofill` 구역). 한 장의 두 파일을 다 쓴 뒤에 돌릴 것(먼저 돌리면 중복 키).
- `tools/kocries.py`: 초코보 울음·이름 줄(번호 < 100)을 다른 장 번역에서 모아 `29_cries.tsv` 재생성.
- 번역 결정 사항:
  - 街 = 「마을」(시간을 잊는 마을·시간을 새기는 마을), 用語辞典 = 용어 사전, 말투 표는 `02_용어표.md` 와 각 TSV 머리 주석.
  - 편지(ITEM_ALL_TXT1 456–496)의 분홍 글자 합언어는 **한국어 발음**으로(つ=쓰, 긴 う=우). 504 는 줄 첫 글자 세로 읽기 「기관차조사해보라고요」.
  - 크레디트(EVTMSG10): 영문 2–65 그대로, 일본어 장난 크레디트 81–117 번역(이름은 성·이름 순서, 거센소리). 초록 세로 글자 코·우·사·쿠·카와모토, 무지개 요·코·야·마·유·우·키. 크레디트만으로 음절 13개 늘어남 — 음절이 모자라면 크레디트를 원문 가나로 되돌리는 것도 방법(가나 칸을 남길 경우).
  - `┣┳`(좁은 「ギル」) → 「길」, `⑮`(転) → 「전생」 으로 바꿔도 됨(검사기 허용).

## 6. 글꼴 구조 바꾸기 — 한글 사용자 영역 코드(2026-09-25 클라우드, **실기 미확인**)
- 전: 한자 쌍(CMAP 방식 2, 코드·번호 4 B)의 코드를 한글로 바꿔 끼움 → 한 자 20 B, 한자 칸 606 이 한도.
- 후: 쓰는 음절만 **U+F000‥ 에 차례로** 붙여(`josa.assign`) 글꼴에 **방식 0(연속 범위) 한 블록** — 한 자 = 비트맵 13 + 폭 3 = 16 B, 쌍 없음.
  - 순서 = [받침 없음][ㄹ 받침][그 밖 받침] → 조사 훅은 경계값 두 개 비교만(`josa.build`, 172 B).
  - 같은 코드를 UTF-8 대사(`build.remap_text`), SJIS 변환 표(`sjiskr.patch_arm9(remap)`), 조사 표, 글꼴에 쓴다. 번역 TSV·검사기는 그대로 한글.
  - 글꼴(`nftr.rebuild`): 한자 전부 + 가나(`--kana all` 남김 / `text` 번역 안 한 글에 남은 가나 99자만)를 글리프째 빼고, 블록마다 원래 범위 유지(뺀 코드는 방식 1 표 0xFFFF), 새 한글 블록은 사슬 맨 앞, 대체 글자 번호도 고침. 조사 «없음» U+E0FF 는 방식 2 쌍.
- `--dry` 출력: 두 가나 방식 모두 「뺀 글자 · 크기 · 여유(한글 몇 자 더/넘음) · 번호 바뀐 글리프」. **번호 바뀐 글리프**가 있으면 게임이 글리프를 번호로 직접 그리는 곳(커서·아이콘 등)이 틀어질 수 있음 — 실기에서 확인.
- 검산 `python tools/test_pua.py`(ROM 없이): 훅을 unicorn 으로 실제 명령 실행(1,013음절 × 조사 7, 틀림 0) · 가짜 NFTR 로 rebuild 왕복 · 빌드 이음(UTF-8·SJIS 표·글꼴 코드 일치). 필요 패키지 keystone-engine·capstone·unicorn·pillow·numpy·ndspy.
- 실기에서 볼 것: 부팅 · 대사·아이템 이름 한글 · 조사(받침/ㄹ/없음) · 아이콘 글자(키릴·괘선 자리) · 합언어 입력 화면 가나 · 폭 계산(줄 넘침).
- `--kana text` 는 합언어 자판에서 정답에 없는 가나를 누르면 대체 글자로 보일 수 있음(자판 구조는 `tools/kbddump.py` 로 조사).
