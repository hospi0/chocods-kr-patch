## 9. PoC-1 결과 — ❌부팅 실패 = SYS 힙 부족 (2026-09-24)
- 사용자 스테이트(`D:\hospi\melonDS\state\…ml1`) 해독: 스테이트 +0x24 = 주 RAM 0x02000000. ARM9 가 **어보트 모드**(CPSR 0x97), 어보트 LR `0x2083664`(오버레이 0/2, 0x2055e00~).
- `0x2083614` 함수가 `alloc(0x6000, 0x10)`(`0x20805dc` → 힙 핸들 표 `0x2174244`[2] = SYS) 을 2번 부르는데 **두 번째가 NULL** → `memset(NULL, 0, 0x6000)` 에서 터짐.
- 힙 = NNS 확장 힙('EXPH'). **SYS** `0x21754f0`(149,448 B) / **APP** `0x2199d00`(2.38 MB).
  - 원본 실행(`my files` 스테이트 7개, 타이틀~던전): SYS 사용 10블록 144,840 B · **빈 곳 4,416 B**(글꼴 27,000 B 가 여기 있음). APP 도 던전에서 빈 곳 28,440 B 뿐.
  - PoC-1 글꼴 74,000 B(+47,000) → SYS 빈 곳 24,032 B < 0x6000 → 실패.
- 결론: **글꼴은 원본 크기 + 약 4 KB 까지만**(빌더 `FONT_GROW_MAX = 2000` 으로 막음). 글자 한 개 = 비트맵 13 + 폭 3 + CMAP 쌍 4 = 20 B.
  - 본번역 때 = 가나 177 + 한자 606 = 783 칸을 한글로 **갈아 끼움**(같은 크기). 코드를 연속 범위(CMAP 방식 0)로 두면 글자당 16 B → 약 1,100~1,200 음절까지.
