# 시드와 초코보의 이상한 던전 - 시간을 잊는 미궁 DS+ 한글 패치

닌텐도 DS 일본판 『シドとチョコボの不思議なダンジョン 時忘れの迷宮 DS+』(CCTJ)의 비공식 한글 패치입니다.

## 내려받기

**[릴리즈 페이지](https://github.com/hospi0/chocods-kr-patch/releases/latest)** 에서 `ChocoboDS_KR_v0.9.zip` 을 받으세요.

| | MD5 |
|---|---|
| 원본 `Cid to Chocobo no Fushigi na Dungeon - Toki Wasure no Meikyuu DS+ (Japan).nds` | `97F8E08589ADC30F4F026B64B88B5D48` |
| 패치 결과 | `5E065EC981709D8EB8DC99890441E4E3` |

## 적용 방법

1. 원본 .nds 파일과 패치 묶음을 한 폴더에 둡니다.
2. `패치적용.bat` 을 실행합니다.
3. 배치가 원본 MD5 를 먼저 확인하고, 끝난 뒤 결과 MD5 까지 검사합니다. 원본은 `.bak` 으로 남겨 둡니다.

배치를 쓰지 않을 때는 xdelta3 로 직접 적용해도 됩니다.

```
xdelta.exe -d -s "원본.nds" ChocoboDS_KR_v0.9.xdelta "결과.nds"
```

## 바뀌는 것

- 본편 대사·메뉴·아이템·몬스터·어빌리티·편지·시스템 문구 전부
- 그림 글자(타이틀·HUD·메뉴·장 제목·직업명·던전 이름·지명·출구 표시 등)
- 영상 자막 2편(데모 A·B)
- 조사(을/를·이/가…) 자동 선택
- 카드 게임 「팝업 듀얼」: 카드 이름·설명, 튜토리얼, 그림책 게임 설명, 대전·결과·Wi-Fi·덱 편집 화면
- 합언어(비밀번호) 입력: 한글 자판 + 한국어 정답 — 정답 목록은 패치 묶음의 `readme.txt` 에 있습니다
- 이름·덱 이름 입력 자판 한글

## 알려진 사항

- 이름 입력 자판은 칸 수 때문에 쓸 수 있는 음절이 정해져 있습니다.
- 오프닝 영상의 제목 로고와 제작진 명단은 원문 그대로입니다.
- 예전 판의 세이브스테이트를 불러오면 글자가 어긋나 보일 수 있습니다.
